How to Use the Logic Playground

Complete guide to building, simulating and saving digital circuits.

🎯 Quick Start

  1. Add gates: Drag from the left palette onto the canvas, or click a gate in the palette to add it at the center.
  2. Connect gates: Press W to enter Wire mode, then click an output port and drag to an input port.
  3. Toggle inputs: Click INPUT or SWITCH nodes in select mode, or double-click them.
  4. Simulate: Changes propagate automatically — see outputs update in real time.

⌨️ Keyboard Shortcuts

V Select mode — click to select/move gates
W Wire mode — click output port → input port
D Delete mode — click gates or wires to remove
Delete / Backspace Delete selected gate(s)
Ctrl+Z Undo last action
Ctrl+Shift+Z Redo last undone action
Ctrl+S Save circuit to browser storage
Escape Cancel wire drawing / deselect all
Space Toggle waveform pause/play
Scroll wheel Zoom in/out
Alt+Click drag Pan the canvas
Shift+Click Multi-select gates

🔗 Wiring Instructions

  1. Press W to enter Wire mode (cursor becomes crosshair).
  2. Click on an output port (circle on the right side of a gate).
  3. Drag to an input port (circle on the left side of a gate).
  4. Release to create the wire connection.
  5. Fan-out is supported: one output can connect to multiple inputs.
  6. Press Escape or click empty space to cancel a wire in progress.

📊 Simulation

The circuit simulates automatically whenever:

  • An input is toggled
  • A gate is added or removed
  • A wire is connected or disconnected
  • A constant value is changed

Signal values propagate through the circuit using topological ordering. The waveform panel below the canvas records a timing diagram of all input and output signals over time.

Press Space to pause/resume waveform recording.

💾 Save / Load

  • Save (Ctrl+S): Stores the circuit in your browser's local storage.
  • Load: Restores the last saved circuit from local storage.
  • Export: Downloads the circuit as a .json file.
  • Import: Upload a previously exported .json circuit file.
  • Clear: Removes all components (with confirmation).

💡 Tips

  • Use CONST 0 and CONST 1 for fixed values that don't change during simulation.
  • Wire value badges (0/1) appear on wire midpoints showing the current signal.
  • The Fit button auto-zooms to show all components.
  • Multi-select gates with Shift+Click, then press Delete to remove them all.
  • The canvas supports unlimited panning — drag on empty space to move around.
