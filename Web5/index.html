How the Sequential Simulator Works

All flip-flops are negative-edge triggered: state changes only when CLK falls from 1 to 0.

🎯 Quick Start

  1. Press Run to start the shared clock (or Space).
  2. Toggle inputs (S, R, J, K, T, D) with the buttons — schematics and wires update live.
  3. Watch the red ▼ lines in each waveform: that is where the clock falls and Q updates.
  4. Use Step (N) to advance one half period manually.
  5. Reset All clears every flip-flop back to Q = 0.

🧠 Flip-Flop Reference

FFInputsBehaviour at ↓ edge
SRS, RSet / Reset / Hold (S=R=1 forbidden)
JKJ, KSet / Reset / Hold / Toggle
TTToggle when T=1, hold when T=0
DDQ copies D at the edge

Why negative edge? Many real devices (e.g. 74LS76 JK, 7476) are triggered on the falling clock edge — the bubble + triangle symbol on each schematic marks this.

📊 Reading the Waveforms

  • Each row shows one signal over time: CLK (amber), inputs (blue), Q (green) and Q̄ (dashed green).
  • The 0/1 value of every signal is printed along its trace.
  • Vertical red dashed lines mark negative clock edges — Q changes exactly at those instants (never while CLK is high).
  • History keeps the last ~48 samples and scrolls as the clock runs.

⌨️ Controls

Space Run / pause the clock
N Step one half period (pauses first)
Click input Toggle that flip-flop input
⟲ Q=0 Reset an individual flip-flop

💡 Tips

  • Set J = K = 1 (or T = 1) and run the clock: Q toggles once per period — a frequency divider (f/2).
  • Drive the D flip-flop with a pattern and watch Q repeat it one edge later — that's the "delay" behaviour.
  • SR with S = R = 1 is highlighted red as INVALID; the simulator holds the previous state.
  • Pause the clock and use Step for precise single-edge experiments.
